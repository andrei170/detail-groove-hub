The four installs sequenced

Install 1 - Detailer Readiness Scorecard

Surface. scorecard.detailgroove.co (or detailgroove.co/scorecard - lock with Oscar Day 1)

Build. - 10 questions (revenue band, service line, employee count, primary bottleneck, tools owned, marketing surface, pricing model, lead-gen surface, fulfilment capacity, time-in-business) - 4 routing bands: Just Starting / Building To $1K / Building To $5K / Building To $20K - Email capture before result reveal - Tag map fires into the email platform (ConvertKit / GHL / whatever Oscar uses) - Result page: 3-line bottleneck readout + tier-appropriate recommendation + scorecard-nurture sequence kicks off

Year-1 lift basis. Email capture across the full existing storefront traffic + every routed YouTube / IG / podcast click.

Install 2 - Pre-sell VSL on detailgroove.co

Surface. detailgroove.co homepage, above the existing lead magnet opt-in. Mirror-embedded on the Detailers Growth Academy sales page.

Build. - 5-7 minute VSL - Filmed at the R3 Auto Detailing shop, Cutten Rd Houston - Oscar on camera, operator-educator register - Script structure: hook (the audience-vs-funnel disparity from the inside) -> ladder explanation ($0 -> $1K -> $5K -> $20K) -> all-access pre-sell -> scorecard CTA - AG1 scripts. AG1 directs the record. AG1 edits. AG1 embeds.

Year-1 lift basis. Conversion lift on existing storefront traffic. Compounds against every routed YouTube end card.

Install 3 - Detailer Operator Cohort (application-gated)

Surface. cohort.detailgroove.co (or detailgroove.co/cohort - lock Day 1) + Typeform application + cohort-application post-submit sequence.

Build. - Landing page: hero + who-it-is-for (3 archetypes) + the work (4 modules) + about Oscar + receipts (placeholder for inaugural cycle) + FAQ + apply - Typeform application: ~12 questions, manual review by Oscar - Cycle structure: 8-12 operators per cycle, 2 days in-person at the R3 shop, 8-12 week implementation runway with weekly group call - Mid-tier mentorship pricing (above the all-access membership, in the mid-five-figure band) - Refund policy locks per cycle

Year-1 lift basis. 4 cycles per year x 8-12 seats x mid-tier mentorship pricing. Highest-margin line in the catalog once it exists.

Install 4 - Buyer-tier segmented welcome flow

Surface. Webhook handler on every Teachable / Circle / SamCart purchase event + email-platform tag map + per-tier welcome templates.

Build. - Webhook fires on every purchase - Tag applied: SKU + price band + tier - Welcome sequence forks per tier: - Social Media For Detailers / SEO For Detailers / Detailing as a Business buyer -> 7-day welcome + Day 30 soft all-access upsell - Detailers Growth Academy all-access buyer -> 7-day welcome + Day 30 cohort application invite - 2-Day In-Person buyer -> 7-day welcome + Day 14 cohort application invite (post-class) - Lead magnet PDF nurture flow gets a content-origin tag so AG1 can read attribution downstream

Year-1 lift basis. Upgrade capture on the existing buyer base + every future buyer who enters the catalog.
