Install Priority + Timeline

Install What Timeline Complexity
1 Business-readiness quiz + email segmentation Days 1-21 Medium
2 Cohort funnel (waitlist, VSL, onboarding, call infra) Days 14-45 Medium-High
3 "Start Here" pathway page + navigation update Days 1-7 Low
4 Podcast outro + podcast landing page Days 1-10 Low
5 Online workshop intensive (optional parallel track) Days 30-60 Medium

Recommended sequence: Install 3 and 4 first (lowest complexity, immediate revenue lift from existing traffic). Install 1 second (quiz build activates email segmentation before cohort launches). Install 2 third (cohort goes live with a segmented waitlist already built from Install 1). Install 5 in parallel once cohort is running.

Tech Stack (AG1 standard for this install)

Function Tool
Quiz build + segmentation Typeform (logic branches) or ConvertKit quiz
Email platform ConvertKit (segment tags by quiz output)
Cohort call infrastructure Zoom or Riverside (weekly group calls)
Cohort community Skool (discussion, resource library, call replays)
Cohort checkout Whop or Teachable (if already on platform)
Landing pages GHL or Webflow (match existing brand)
Podcast landing Simple HTML page or GHL
CRM GHL (if not already in use at Detail Groove)
Payment Stripe via Whop or Teachable
Analytics GA4 + ConvertKit reporting

Note: If Detail Groove already uses Teachable for courses, cohort checkout can run on the same platform to minimize vendor sprawl. Confirm at kickoff.
